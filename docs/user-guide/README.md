# ELC Platform — User Guide

A guide to the NavGurukul **PnC ELC Platform** (Employee Life Cycle) for the
people who use it: the People & Culture (PnC) team, the Finance team,
leadership, managers and employees.

Read this before you start using the site. You don't need any technical
knowledge for it.

**Printable copy:** [ELC-Platform-User-Guide.pdf](ELC-Platform-User-Guide.pdf) has
the whole guide in one file to share or print.

> **Scope.** This guide describes the platform as built at version **2.04.00**
> (October 2026). Where a screen is still unfinished, or shows sample data,
> the guide says so. [Known limitations](13-known-limitations.md) collects
> these in one place.

---

## What the platform is

The ELC Platform is NavGurukul's single place to run every stage of a
person's time with us:

```
 Candidate ──► Pre-joiner ──► Employee (probation) ──► Confirmed employee ──► Exit
   offer       documents,      Day 1, check-ins,        appraisals          resignation,
   letters     signing         confirmation review                          clearances, F&F
```

| Stage | What the platform does |
|---|---|
| **Onboarding** | Creates the offer, generates letters, sends the candidate a portal link, collects documents and signatures, and lets PnC verify everything before the person becomes an employee. |
| **Employee records** | Keeps the directory of everyone who works here, with reporting lines, teams and documents. |
| **Confirmation** | Runs the probation review: the employee's self-reflection, peer feedback, the manager's review, a meeting, and a decision PnC accepts. |
| **Appraisals** | Runs the twice-yearly performance reviews in the same way. |
| **Offboarding** | Handles a resignation, the notice period, departmental clearances (No Dues), full-and-final settlement and the relieving letter. |
| **Payroll** | *Planned, not yet built.* See the [Finance guide](11-finance-guide.md). |

## Getting help

- **Something looks wrong, or you can't reach a screen you need:** ask a PnC
  Admin. Access is set by role, and only certain people can change roles (see
  [Roles and access](02-roles-and-access.md#who-can-give-someone-a-role)).
- **A setting needs changing:** ask a Platform Admin.
- **Candidates** with questions about their portal write to the PnC mailbox
  shown on their portal page.
