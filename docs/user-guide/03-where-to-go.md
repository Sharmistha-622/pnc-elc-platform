# 3. Where to go to do what

Find what you want to do, then go to the place listed. The **Who** column
lists the roles that can do it.

## Everyone

| I want to… | Go to | Who |
|---|---|---|
| See what's waiting on me | **Dashboard** → *Waiting on you* | All staff |
| Fill in a form I've been sent (self-reflection, peer feedback, manager review) | **My Workspace › My Forms** | All staff |
| See where my confirmation or appraisal review stands | **My Workspace › My Reviews** | All staff |
| Nominate peers for my review | **My Reviews** → open the review → *Save nominations* | All staff |
| See my joining date, manager and confirmation status | **My Workspace › My Profile** | All staff |
| See what changed in the latest release | `/changelog` | All staff |
| Switch dark mode on or off | ☀/☾ in the header | All staff |

## Managers

| I want to… | Go to | Who |
|---|---|---|
| See the people who report to me | **My Workspace › My Team** | Anyone with reports |
| Fill in the manager review for a report | **My Reviews** → *My team's reviews* → open → *Fill in the manager review* | Their manager |
| Book or move a report's review meeting | **My Reviews** → open the review → *Review meeting* | Their manager |
| Record the outcome after the meeting | **My Reviews** → open the review → *Decision* → *Record decision and send to PnC* | Their manager |

## PnC

| I want to… | Go to | Who |
|---|---|---|
| Make an offer to a new candidate | **People › Onboarding › Candidates** → *Create Candidate* | PnC Admin, Super Admin |
| Send or resend a candidate's portal link | **Candidates** → ⋮ → *Send / Resend Invitation Email* | PnC Admin, PnC Ops |
| Verify a candidate's documents | **Candidates** → *Review* → **Verification** tab | PnC Admin, PnC Ops |
| Ask a candidate to fix something | Review page → *Request Changes* (or *Reject* a single document) | PnC Admin, PnC Ops |
| Approve a candidate and make them an employee | Review page → *Approve Dossier* → *Create Official Account* | PnC Admin, PnC Ops |
| Track Day-1, laptop, POSH and 30/60-day check-ins | **Onboarding › New Joiners** | PnC Admin, PnC Ops |
| Edit an offer/appointment letter template | **People › Letters › Templates** | PnC Admin |
| Change who signs letters | **People › Letters › Signatories** | PnC Admin |
| Find a letter already issued | **People › Letters › Issued Letters** | PnC Admin, Fin Admin |
| Change someone's reporting manager | **Data Management › Import Employee Data**: upload a CSV with their `email` and new `manager_email` (see [Administration](10-administration.md#import-employee-data)) | PnC Admin, Super Admin |
| Edit an employee's personal details | **Employees** → *View* → *Save Profile Changes* | PnC Admin, PnC Ops |
| Upload a document to an employee's file | **Employees** → *Documents* | PnC Admin, PnC Ops |
| See every confirmation/appraisal review in progress | **People › Reviews** | PnC Admin, PnC Ops, Exec View |
| Start a review that is due but hasn't opened | **Reviews** → *Due, not started* → *Start now* | PnC Admin, PnC Ops |
| Chase people who haven't responded | **Reviews** → *Remind all pending*, or the review → *Remind* | PnC Admin, PnC Ops |
| Add or withdraw a peer reviewer | **Reviews** → open the review | PnC Admin, PnC Ops |
| Accept a manager's decision, or send it back | **Reviews** → open the review → *Accept and close* / *Send back to the manager* | PnC Admin |
| Record a resignation | **People › Offboarding** → *Initiate Resignation* | PnC Admin, PnC Ops |
| Run an exit (checklist, assets, No Dues) | **Offboarding** → *Manage Case* | PnC Admin, PnC Ops |
| Give a colleague a PnC role | **Administration › Users & Roles** | PnC Admin |
| Load many employees at once from a spreadsheet | **Administration › Data Management › Import Employee Data** | PnC Admin, Super Admin |
| See the history of everything done to one employee | **Administration › Audit Trail** | PnC Admin, Platform roles |

## Finance

| I want to… | Go to | Who |
|---|---|---|
| Look someone up (team, type, joining date, exit date) | **People › Employees** | Fin Admin, Fin Ops |
| See who joined or is leaving this month | **Dashboard** → *At a glance* | Fin Admin, Fin Ops |
| See exits waiting for full-and-final | **Dashboard** → *Settlements due*, or **Offboarding** → *F&F Pending* tab | Fin Admin |
| Clear the Finance No Dues for an exit | **Offboarding** → *Manage Case* → **Departmental NDC** | Fin Admin |
| Record a full-and-final settlement | **Offboarding** → *Manage Case* → **F&F Settlement** → *Update Settlement* | Fin Admin |
| Read an offer or appointment letter | **People › Letters › Issued Letters** | Fin Admin |
| Download a headcount list | **Insights › Reports** → *Headcount & Demographics* → *Export CSV* | Fin Admin |
| Give a colleague a Finance role | **Administration › Users & Roles** | Fin Admin |
| Run payroll | *Not built yet.* See the [Finance guide](11-finance-guide.md). | — |

## Platform team

| I want to… | Go to | Who |
|---|---|---|
| Change review timings, reminder cadence, confirmation periods | **Administration › Settings** | Platform Admin |
| Check whether emails were sent or failed | **Administration › Email Center** → *Delivery Monitor & Outbox* | Platform Admin |
| Edit the self-reflection, peer or manager review questions | **Administration › Form Builder** | Platform Admin |
| Add a department, location or employment type | **Administration › Data Management** | Platform Admin, PnC Admin |
